# 청개구리 환희 지표

[시장 심리 점수](https://github.com/rtyui32123-del/market-fear-greed)를 거꾸로 뒤집은 재미용 반대 버전입니다.
시장이 겁에 질릴수록 점수가 높아지고 표정이 밝아집니다 (점수 = 100 - 원래 점수).

웹에서 보기: https://rtyui32123-del.github.io/claude-chrome-demo/

- 0~25 매우 시무룩 / 25~45 시무룩 / 45~55 그저 그럼 / 55~75 신남 / 75~100 환희
- 지표, 가중치 산출 방식, 갱신 주기(약 1시간)는 원래 버전과 같습니다.

재미로 만든 것이며, 점수가 높다고 사라는 뜻이 아닙니다. 주가 예측이나 투자 권유가 아닙니다.
